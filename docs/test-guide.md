# myfolio 테스트 안내 (함께 테스트하는 분용)

**테스트 주소:** https://myfolio-git-feat-signup-onboarding-myfoilo.vercel.app

- 휴대폰·PC 어디서나 열려요 (로그인 없이 접속 가능)
- 지금은 **테스트 기간이라 모든 기능 무료**예요 (다운로드·공개·사진·영상·경력 제한 없음)
- 실제 서비스와 같은 DB를 써요. 테스트로 만든 계정·카드는 나중에 지울 수 있어요

## 로그인
- **구글 로그인**으로 들어와 주세요
- 카카오 로그인은 아직 설정 중이라 오류(KOE205)가 나요 — 정상이에요
- 구글에서 "이 앱은 확인되지 않았습니다" / "액세스 차단" 같은 화면이 나오면 알려 주세요 (테스트 사용자 등록이 필요할 수 있어요)

## 테스트해 볼 것 (순서대로)
1. **가입:** 처음 로그인하면 프로필 입력 → 저장
2. **컴카드 만들기:** 메뉴 Comp Card → 세로/가로 → 장수(3~6) → 사진 올리기 → 표시할 정보 → 양식 고르기 → 편집
   - 사진과 글자 끝선이 맞는지, 빈 칸이 없는지, 사진이 잘 채워지는지 봐 주세요
   - 사진 이동·크기 조절, 색·글자 크기 바꾸기, 되돌리기
3. **저장·다운로드:** "마이페이지에 저장", "SAVE IMAGE"(PNG), "DOWNLOAD PDF"
4. **공유:** "공유하기 (링크)" → 받은 링크를 다른 기기(휴대폰)에서 열어 보기
5. **마이페이지:** 내 명함 주소 정하기, QR 보기, 링크 복사
6. **명함 페이지:** "포트폴리오 보기" → 연락처 저장, 사진·영상 탭
7. **포트폴리오 사진:** 마이페이지 "사진 관리" → 사진 올리기 → 촬영 컨셉 고르기·바꾸기
8. **AI 추천:** 아직 꺼져 있어요 ("AI 설정 전이라 올린 순서대로" 안내가 정상)

## 불편·오류 알려 주기
- 화면 메뉴의 **"의견 보내기"**로 보내 주세요 — 운영자 화면에 바로 모이고, 매주 자동 분석돼요
- 화면 오류는 자동으로 기록돼요. 그래도 "어느 화면에서 무엇을 눌렀을 때"를 함께 적어 주시면 가장 빨리 고칠 수 있어요
- 기기 종류(아이폰/갤럭시/PC)와 브라우저도 적어 주세요
